A single Node 22 CLI that applies AI-written edits in all four formats of make.fun's `hidden-spec-cli` specification: unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON editor tool calls. It finds the lines an edit names at the first of three whitespace-tolerance tiers, and changes every file or none.
